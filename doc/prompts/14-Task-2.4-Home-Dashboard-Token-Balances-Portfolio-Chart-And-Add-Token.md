### 2. TokenRepository Interface (domain module)

```kotlin
package com.nexvault.wallet.domain.repository

import com.nexvault.wallet.domain.model.Token
import com.nexvault.wallet.domain.model.PricePoint
import kotlinx.coroutines.flow.Flow
import java.math.BigDecimal

/**
 * Repository for token balance and price data.
 *
 * Provides cached token data via Room and supports refreshing from
 * on-chain (Web3j) and price API (CoinGecko) sources.
 *
 * Ref: doc/05-IMPLEMENTATION-PLAN-PHASE2.md Task 2.4.2
 */
interface TokenRepository {

    /**
     * Observes all tokens with balances for a given chain and wallet address.
     *
     * Returns cached data from Room as a Flow. Data updates when
     * [refreshBalances] is called successfully.
     *
     * @param chainId The blockchain network chain ID
     * @param address The wallet address to query balances for
     * @return Flow of token list, sorted by fiat value descending
     */
    fun getTokensWithBalances(chainId: Int, address: String): Flow<List<Token>>

    /**
     * Fetches fresh balance and price data from on-chain and API sources.
     *
     * Steps:
     * 1. Fetch native coin balance via ethGetBalance
     * 2. Fetch ERC-20 balances via balanceOf calls
     * 3. Fetch fiat prices from CoinGecko
     * 4. Update Room database
     *
     * @param chainId The chain to refresh on
     * @param address The wallet address
     * @throws IOException on network failure
     */
    suspend fun refreshBalances(chainId: Int, address: String)

    /**
     * Adds a custom ERC-20 token by its contract address.
     *
     * Fetches the token's name, symbol, and decimals from the chain
     * to validate it's a real ERC-20 contract.
     *
     * @param chainId The chain the token is on
     * @param contractAddress The ERC-20 contract address
     * @return The newly added Token, or failure if invalid
     */
    suspend fun addCustomToken(chainId: Int, contractAddress: String): Result<Token>

    /**
     * Removes a token from the user's tracked list.
     *
     * @param chainId The chain
     * @param contractAddress The token contract address to remove
     */
    suspend fun removeToken(chainId: Int, contractAddress: String)

    /**
     * Fetches price chart data for the portfolio or a specific token.
     *
     * @param coinGeckoId The CoinGecko ID of the token
     * @param vsCurrency The fiat currency code (e.g., "usd")
     * @param days Number of days of history (1, 7, 30, 90, 365)
     * @return List of price points for charting
     */
    suspend fun getPriceHistory(
        coinGeckoId: String,
        vsCurrency: String,
        days: Int,
    ): Result<List<PricePoint>>

    /**
     * Seeds the database with default tokens for a chain.
     *
     * Called after wallet creation to pre-populate the token list.
     * Balances will be zero until [refreshBalances] is called.
     *
     * @param chainId The chain to seed tokens for
     */
    suspend fun seedDefaultTokens(chainId: Int)
}
```

**CRITICAL INSTRUCTIONS FOR THE AI:**
1. **Check if `TokenRepository` already exists.** Update if so.
2. The interface lives in `domain` — it has no Android or library dependencies.
3. `refreshBalances` does NOT return a value — it updates Room, and the
   `getTokensWithBalances` Flow automatically emits the new data.
4. `seedDefaultTokens` is called once after wallet creation.

### 3. TokenRepository Implementation (data module)

This is the most complex implementation. It bridges Web3j (on-chain data),
CoinGecko (prices), and Room (cache).

```kotlin
package com.nexvault.wallet.data.repository

import javax.inject.Inject
import javax.inject.Singleton

/**
 * Implementation of [TokenRepository] using Web3j for on-chain balances,
 * CoinGecko for fiat prices, and Room for local caching.
 *
 * Ref: doc/05-IMPLEMENTATION-PLAN-PHASE2.md Task 2.4.3
 * Ref: doc/09-PERFORMANCE-OPTIMIZATION.md Section 3.1 (batch calls), 3.3 (dedup)
 */
@Singleton
class TokenRepositoryImpl @Inject constructor(
    private val tokenDao: TokenDao,         // from core-database
    private val coinGeckoApi: CoinGeckoApi, // from core-network
    private val web3jProvider: Web3jProvider,// from core-network
    private val chainRepository: ChainRepository, // from domain (bound via data)
) : TokenRepository {

    /**
     * Mutex to prevent concurrent refresh calls (e.g., rapid pull-to-refresh).
     * Ref: doc/09-PERFORMANCE-OPTIMIZATION.md Section 3.3
     */
    private val refreshMutex = kotlinx.coroutines.sync.Mutex()

    override fun getTokensWithBalances(chainId: Int, address: String): Flow<List<Token>> {
        return tokenDao.getTokensByChain(chainId).map { entities ->
            entities.map { it.toDomain() }
        }
    }

    override suspend fun refreshBalances(chainId: Int, address: String) {
        if (!refreshMutex.tryLock()) return // already refreshing
        try {
            val chain = chainRepository.getChainById(chainId) ?: return
            val web3j = web3jProvider.getWeb3j(chain) // check actual method signature

            // 1. Fetch native coin balance
            val nativeBalanceWei = web3j.ethGetBalance(
                address,
                org.web3j.protocol.core.DefaultBlockParameterName.LATEST
            ).send().balance
            val nativeBalance = java.math.BigDecimal(nativeBalanceWei)
                .divide(java.math.BigDecimal.TEN.pow(18))

            // 2. Get tracked tokens from Room
            val trackedTokens = tokenDao.getTokensByChainOnce(chainId)

            // 3. Fetch ERC-20 balances
            val erc20Balances = mutableMapOf<String, java.math.BigDecimal>()
            for (token in trackedTokens) {
                if (token.contractAddress == "native") continue
                try {
                    val balanceWei = callBalanceOf(web3j, token.contractAddress, address)
                    val balance = java.math.BigDecimal(balanceWei)
                        .divide(java.math.BigDecimal.TEN.pow(token.decimals))
                    erc20Balances[token.contractAddress] = balance
                } catch (e: Exception) {
                    // Skip failed tokens, keep previous balance
                }
            }

            // 4. Fetch fiat prices from CoinGecko
            val allCoinGeckoIds = buildList {
                add(chain.nativeCoinCoinGeckoId)
                trackedTokens.mapNotNull { it.coinGeckoId }.forEach { add(it) }
            }.distinct()

            val priceMap = try {
                val idsString = allCoinGeckoIds.joinToString(",")
                coinGeckoApi.getTokenPrices(
                    ids = idsString,
                    vsCurrencies = "usd",
                    include24hChange = true,
                )
            } catch (e: Exception) {
                emptyMap() // prices unavailable, use cached
            }

            // 5. Build updated token entities and upsert
            val now = System.currentTimeMillis()
            val updatedEntities = mutableListOf<TokenEntity>()

            // Native coin
            val nativePriceData = priceMap[chain.nativeCoinCoinGeckoId]
            val nativePrice = nativePriceData?.usd
            val nativeFiatValue = if (nativePrice != null) {
                nativeBalance.toDouble() * nativePrice
            } else null

            updatedEntities.add(
                TokenEntity(
                    contractAddress = "native",
                    chainId = chainId,
                    symbol = chain.symbol,
                    name = chain.nativeCoinName,
                    decimals = 18,
                    logoUrl = null,
                    balance = nativeBalance.toPlainString(),
                    fiatPrice = nativePrice,
                    fiatValue = nativeFiatValue,
                    priceChange24h = nativePriceData?.usd24hChange,
                    coinGeckoId = chain.nativeCoinCoinGeckoId,
                    isCustom = false,
                    sortOrder = 0,
                    lastUpdated = now,
                )
            )

            // ERC-20 tokens
            for (token in trackedTokens) {
                if (token.contractAddress == "native") continue
                val balance = erc20Balances[token.contractAddress]
                    ?: java.math.BigDecimal(token.balance) // keep cached if fetch failed
                val tokenPriceData = token.coinGeckoId?.let { priceMap[it] }
                val price = tokenPriceData?.usd ?: token.fiatPrice
                val fiatValue = if (price != null) balance.toDouble() * price else token.fiatValue

                updatedEntities.add(
                    token.copy(
                        balance = balance.toPlainString(),
                        fiatPrice = price,
                        fiatValue = fiatValue,
                        priceChange24h = tokenPriceData?.usd24hChange ?: token.priceChange24h,
                        lastUpdated = now,
                    )
                )
            }

            tokenDao.upsertTokens(updatedEntities)

        } finally {
            refreshMutex.unlock()
        }
    }

    override suspend fun addCustomToken(chainId: Int, contractAddress: String): Result<Token> {
        return try {
            val chain = chainRepository.getChainById(chainId)
                ?: return Result.failure(IllegalArgumentException("Unknown chain: $chainId"))
            val web3j = web3jProvider.getWeb3j(chain)

            // Fetch token metadata from chain
            val name = callErc20Name(web3j, contractAddress)
            val symbol = callErc20Symbol(web3j, contractAddress)
            val decimals = callErc20Decimals(web3j, contractAddress)

            val entity = TokenEntity(
                contractAddress = contractAddress.lowercase(),
                chainId = chainId,
                symbol = symbol,
                name = name,
                decimals = decimals,
                logoUrl = null,
                balance = "0",
                fiatPrice = null,
                fiatValue = null,
                priceChange24h = null,
                coinGeckoId = null, // custom tokens won't have CoinGecko ID initially
                isCustom = true,
                sortOrder = 100,
                lastUpdated = System.currentTimeMillis(),
            )
            tokenDao.upsertTokens(listOf(entity))

            Result.success(entity.toDomain())
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    override suspend fun removeToken(chainId: Int, contractAddress: String) {
        tokenDao.deleteToken(contractAddress, chainId)
    }

    override suspend fun getPriceHistory(
        coinGeckoId: String,
        vsCurrency: String,
        days: Int,
    ): Result<List<PricePoint>> {
        return try {
            val response = coinGeckoApi.getPriceHistory(
                id = coinGeckoId,
                vsCurrency = vsCurrency,
                days = days,
            )
            val points = response.prices.map { (timestamp, value) ->
                PricePoint(timestamp = timestamp.toLong(), value = value)
            }
            Result.success(points)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    override suspend fun seedDefaultTokens(chainId: Int) {
        val existing = tokenDao.getTokenCountByChain(chainId)
        if (existing > 0) return // already seeded

        val defaultTokens = getDefaultTokensForChain(chainId)
        tokenDao.upsertTokens(defaultTokens)
    }

    // --- Private helpers ---

    /**
     * Calls ERC-20 `balanceOf(address)` via raw Web3j eth_call.
     */
    private suspend fun callBalanceOf(
        web3j: org.web3j.protocol.Web3j,
        contractAddress: String,
        walletAddress: String,
    ): java.math.BigInteger {
        // Encode balanceOf(address) function call
        val function = org.web3j.abi.FunctionEncoder.encode(
            org.web3j.abi.datatypes.Function(
                "balanceOf",
                listOf(org.web3j.abi.datatypes.Address(walletAddress)),
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.generated.Uint256>() {})
            )
        )
        val ethCall = web3j.ethCall(
            org.web3j.protocol.core.methods.request.Transaction.createEthCallTransaction(
                walletAddress, contractAddress, function
            ),
            org.web3j.protocol.core.DefaultBlockParameterName.LATEST
        ).send()
        val result = ethCall.value ?: return java.math.BigInteger.ZERO
        if (result == "0x" || result.isEmpty()) return java.math.BigInteger.ZERO
        val decoded = org.web3j.abi.FunctionReturnDecoder.decode(
            result,
            org.web3j.abi.Utils.convert(
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.generated.Uint256>() {})
            )
        )
        return if (decoded.isNotEmpty()) (decoded[0] as org.web3j.abi.datatypes.generated.Uint256).value
        else java.math.BigInteger.ZERO
    }

    private suspend fun callErc20Name(web3j: org.web3j.protocol.Web3j, contract: String): String {
        // Similar pattern: encode "name()" call, decode string result
        val function = org.web3j.abi.FunctionEncoder.encode(
            org.web3j.abi.datatypes.Function(
                "name", emptyList(),
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.Utf8String>() {})
            )
        )
        val result = web3j.ethCall(
            org.web3j.protocol.core.methods.request.Transaction.createEthCallTransaction(
                "0x0000000000000000000000000000000000000000", contract, function
            ),
            org.web3j.protocol.core.DefaultBlockParameterName.LATEST
        ).send()
        val decoded = org.web3j.abi.FunctionReturnDecoder.decode(
            result.value,
            org.web3j.abi.Utils.convert(
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.Utf8String>() {})
            )
        )
        return if (decoded.isNotEmpty()) decoded[0].value as String else "Unknown"
    }

    private suspend fun callErc20Symbol(web3j: org.web3j.protocol.Web3j, contract: String): String {
        val function = org.web3j.abi.FunctionEncoder.encode(
            org.web3j.abi.datatypes.Function(
                "symbol", emptyList(),
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.Utf8String>() {})
            )
        )
        val result = web3j.ethCall(
            org.web3j.protocol.core.methods.request.Transaction.createEthCallTransaction(
                "0x0000000000000000000000000000000000000000", contract, function
            ),
            org.web3j.protocol.core.DefaultBlockParameterName.LATEST
        ).send()
        val decoded = org.web3j.abi.FunctionReturnDecoder.decode(
            result.value,
            org.web3j.abi.Utils.convert(
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.Utf8String>() {})
            )
        )
        return if (decoded.isNotEmpty()) decoded[0].value as String else "???"
    }

    private suspend fun callErc20Decimals(web3j: org.web3j.protocol.Web3j, contract: String): Int {
        val function = org.web3j.abi.FunctionEncoder.encode(
            org.web3j.abi.datatypes.Function(
                "decimals", emptyList(),
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.generated.Uint8>() {})
            )
        )
        val result = web3j.ethCall(
            org.web3j.protocol.core.methods.request.Transaction.createEthCallTransaction(
                "0x0000000000000000000000000000000000000000", contract, function
            ),
            org.web3j.protocol.core.DefaultBlockParameterName.LATEST
        ).send()
        val decoded = org.web3j.abi.FunctionReturnDecoder.decode(
            result.value,
            org.web3j.abi.Utils.convert(
                listOf(object : org.web3j.abi.TypeReference<org.web3j.abi.datatypes.generated.Uint8>() {})
            )
        )
        return if (decoded.isNotEmpty()) (decoded[0].value as java.math.BigInteger).toInt() else 18
    }
}
```

```kotlin
import com.nexvault.wallet.domain.model.Portfolio
import com.nexvault.wallet.domain.model.PricePoint

import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.flatMapLatest
import kotlinx.coroutines.flow.map
import javax.inject.Inject

/**
 * Combines token balances, prices, and chart data into a complete Portfolio.
 *
 * Observes the selected chain and wallet address, and automatically
 * re-emits when either changes.
 *
 * Ref: doc/05-IMPLEMENTATION-PLAN-PHASE2.md Task 2.4.4
 */
class GetPortfolioUseCase @Inject constructor(
    private val tokenRepository: TokenRepository,
    private val chainRepository: ChainRepository,
    private val walletRepository: WalletRepository,
) {
    /**
     * Returns a Flow of the current portfolio.
     *
     * The Flow re-emits whenever the selected chain changes,
     * the wallet changes, or token data is updated in Room.
     */
    operator fun invoke(): Flow<Portfolio> {
        return combine(
            chainRepository.getSelectedChain(),
            walletRepository.getCurrentWallet(),
        ) { chain, wallet ->
            Pair(chain, wallet)
        }.flatMapLatest { (chain, wallet) ->
            if (wallet == null) {
                kotlinx.coroutines.flow.flowOf(
                    Portfolio(
                        totalFiatValue = 0.0,
                        change24hPercent = 0.0,
                        tokens = emptyList(),
                        chartData = emptyList(),
                    )
                )
            } else {
                tokenRepository.getTokensWithBalances(chain.chainId, wallet.address)
                    .map { tokens ->
                        val totalValue = tokens.sumOf { it.fiatValue ?: 0.0 }
                        val weightedChange = calculateWeightedChange(tokens, totalValue)
                        Portfolio(
                            totalFiatValue = totalValue,
                            change24hPercent = weightedChange,
                            tokens = tokens,
                            chartData = emptyList(), // chart loaded separately on demand
                        )
                    }
            }
        }
    }

    private fun calculateWeightedChange(tokens: List<Token>, totalValue: Double): Double {
        if (totalValue == 0.0) return 0.0
        return tokens.sumOf { token ->
            val weight = (token.fiatValue ?: 0.0) / totalValue
            weight * (token.priceChange24h ?: 0.0)
        }
    }
}
```

```kotlin
package com.nexvault.wallet.feature.home

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.launch
import javax.inject.Inject

/**
 * ViewModel for the Home dashboard screen.
 *
 * Manages portfolio data, chart data, chain selection, and token operations.
 *
 * Ref: doc/05-IMPLEMENTATION-PLAN-PHASE2.md Task 2.4.5
 * Ref: doc/09-PERFORMANCE-OPTIMIZATION.md Section 2.1 (Compose stability)
 */
@HiltViewModel
class HomeViewModel @Inject constructor(
    private val getPortfolioUseCase: GetPortfolioUseCase,
    private val refreshBalancesUseCase: RefreshBalancesUseCase,
    private val addCustomTokenUseCase: AddCustomTokenUseCase,
    private val getPriceHistoryUseCase: GetPriceHistoryUseCase,
    private val getSupportedChainsUseCase: GetSupportedChainsUseCase,
    private val getSelectedChainUseCase: GetSelectedChainUseCase,
    private val setSelectedChainUseCase: SetSelectedChainUseCase,
) : ViewModel() {

    private val _uiState = MutableStateFlow(HomeUiState())
    val uiState: StateFlow<HomeUiState> = _uiState.asStateFlow()

    /** Currently selected chart time range in days. */
    private val _chartDays = MutableStateFlow(7)

    init {
        observePortfolio()
        observeChains()
        loadInitialData()
    }

    private fun observePortfolio() {
        viewModelScope.launch {
            getPortfolioUseCase().collect { portfolio ->
                _uiState.update { state ->
                    state.copy(
                        totalFiatValue = portfolio.totalFiatValue,
                        change24hPercent = portfolio.change24hPercent,
                        tokens = portfolio.tokens,
                        isLoading = false,
                    )
                }
            }
        }
    }

    private fun observeChains() {
        viewModelScope.launch {
            combine(
                getSupportedChainsUseCase(),
                getSelectedChainUseCase(),
            ) { supported, selected ->
                Pair(supported, selected)
            }.collect { (supported, selected) ->
                _uiState.update { state ->
                    state.copy(
                        supportedChains = supported,
                        selectedChain = selected,
                    )
                }
            }
        }
    }

    private fun loadInitialData() {
        viewModelScope.launch {
            _uiState.update { it.copy(isLoading = true) }
            try {
                refreshBalancesUseCase()
            } catch (e: Exception) {
                _uiState.update { it.copy(error = "Failed to load balances. Pull to refresh.") }
            }
        }
    }

    /**
     * Called when user pulls to refresh.
     */
    fun onRefresh() {
        viewModelScope.launch {
            _uiState.update { it.copy(isRefreshing = true, error = null) }
            try {
                refreshBalancesUseCase()
            } catch (e: java.io.IOException) {
                _uiState.update { it.copy(error = "Network error. Please check your connection.") }
            } catch (e: Exception) {
                _uiState.update { it.copy(error = "Failed to refresh. Please try again.") }
            } finally {
                _uiState.update { it.copy(isRefreshing = false) }
            }
        }
    }

    /**
     * Called when user selects a different chain from the dropdown.
     */
    fun onChainSelected(chainId: Int) {
        viewModelScope.launch {
            _uiState.update { it.copy(isLoading = true, error = null) }
            setSelectedChainUseCase(chainId)
            try {
                refreshBalancesUseCase()
            } catch (_: Exception) {
                // cached data will show, error handled in refresh
            }
            // Re-load chart for new chain
            loadChartData()
        }
    }

    /**
     * Called when user selects a chart time range (1D, 7D, 1M, 3M, ALL).
     */
    fun onChartRangeSelected(days: Int) {
        _chartDays.value = days
        loadChartData()
    }

    private fun loadChartData() {
        viewModelScope.launch {
            val chain = _uiState.value.selectedChain ?: return@launch
            // Use the native coin's CoinGecko ID for the portfolio chart
            val coinGeckoId = chain.nativeCoinCoinGeckoId
            val result = getPriceHistoryUseCase(
                coinGeckoId = coinGeckoId,
                days = _chartDays.value,
            )
            result.onSuccess { points ->
                _uiState.update { it.copy(chartData = points, selectedChartDays = _chartDays.value) }
            }
        }
    }

    /**
     * Called when user submits a custom token contract address.
     */
    fun onAddCustomToken(contractAddress: String) {
        viewModelScope.launch {
            _uiState.update { it.copy(addTokenLoading = true, addTokenError = null) }
            val result = addCustomTokenUseCase(contractAddress)
            result.onSuccess { token ->
                _uiState.update { it.copy(
                    addTokenLoading = false,
                    showAddTokenDialog = false,
                    addTokenResult = token,
                ) }
                // Refresh to get the balance
                try { refreshBalancesUseCase() } catch (_: Exception) {}
            }.onFailure { error ->
                _uiState.update { it.copy(
                    addTokenLoading = false,
                    addTokenError = "Invalid contract address or not an ERC-20 token.",
                ) }
            }
        }
    }

    fun onShowAddTokenDialog() {
        _uiState.update { it.copy(showAddTokenDialog = true, addTokenError = null, addTokenResult = null) }
    }

    fun onDismissAddTokenDialog() {
        _uiState.update { it.copy(showAddTokenDialog = false, addTokenError = null) }
    }

    fun onErrorDismissed() {
        _uiState.update { it.copy(error = null) }
    }
}
```

```kotlin
/**
 * Simple line chart drawn on Canvas.
 *
 * If Vico library is available and set up, replace this with Vico's
 * CartesianChartHost for a more polished chart. This Canvas version
 * is a functional fallback.
 */
@Composable
fun SimpleLineChart(
    dataPoints: List<PricePoint>,
    modifier: Modifier = Modifier,
    lineColor: androidx.compose.ui.graphics.Color = MaterialTheme.colorScheme.primary,
) {
    if (dataPoints.size < 2) return

    val minValue = dataPoints.minOf { it.value }
    val maxValue = dataPoints.maxOf { it.value }
    val valueRange = (maxValue - minValue).coerceAtLeast(0.01) // avoid division by zero

    androidx.compose.foundation.Canvas(modifier = modifier) {
        val stepX = size.width / (dataPoints.size - 1)
        val path = androidx.compose.ui.graphics.Path()

        dataPoints.forEachIndexed { index, point ->
            val x = index * stepX
            val y = size.height - ((point.value - minValue) / valueRange * size.height).toFloat()
            if (index == 0) {
                path.moveTo(x, y)
            } else {
                path.lineTo(x, y)
            }
        }

        drawPath(
            path = path,
            color = lineColor,
            style = androidx.compose.ui.graphics.drawscope.Stroke(
                width = 2.dp.toPx(),
                cap = androidx.compose.ui.graphics.StrokeCap.Round,
                join = androidx.compose.ui.graphics.StrokeJoin.Round,
            ),
        )
    }
}
```

`PullToRefreshBox`. In older versions, use `pullRefresh` modifier from Accompanist. Check

the DI graph has issues, create a separate `SeedDefaultTokensUseCase` called from

If you add `coinGeckoId` to `TokenEntity`, the database version must increase.
For development, use `fallbackToDestructiveMigration()`. For production, write a
proper migration. Since this is a development phase, destructive migration is fine.

**Issue: Web3j ethCall returning null or "0x"**
Some tokens or chains may return empty results for `ethCall`. Handle nulls and empty
strings gracefully — return `BigInteger.ZERO` for balance, "Unknown" for name, etc.

**Issue: CoinGecko rate limiting**
The free CoinGecko API has rate limits (~10-30 calls/minute). Batch token IDs into a
single `getTokenPrices` call rather than calling per-token. The code above already does
this by joining all CoinGecko IDs with commas.

loads asynchronously after the initial balance refresh. Call `loadChartData()` in
the ViewModel's `init` block after observing portfolio data.
